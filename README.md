# 📐 Математика · 7 класс: тренажёр по алгебре и геометрии

Статический сайт с классными и домашними работами по **алгебре** (Макарычев, Петерсон, Галицкий) и **геометрии** (Атанасян, Кутузов, Гордин) для 7 класса по ФГОС ООО и ФОП.

* **64 урока** (алгебра 40, геометрия 24), базовый и углублённый уровни; полный перечень тем в [TOPICS.md](TOPICS.md);
* **445 генераторов заданий**: каждый раз новые числа, а **у каждого ученика свой вариант ДЗ** (зависит от имени);
* проверка сразу на странице: зелёный — верно, красный — ошибка; прогресс-бар, таймер, отметка по шкале;
* памятка с правилами и примерами к каждому уроку;
* **отправка результата учителю в Telegram** без своего сервера (GitHub Pages + GitHub Actions + Telegram Bot API);
* хостинг бесплатный (GitHub Pages), никаких зависимостей и сборщиков: чистые HTML, CSS и JS.

## 🧑‍🎓 Как устроена работа ученика

| | Классная работа (К) | Домашнее задание (Д) |
|---|---|---|
| Заданий | 10 | 8 |
| Вариант | новый при каждом открытии | свой у каждого ученика (зерно = имя + урок + попытка) |
| Попытки | без ограничений, подсказки, «Показать ответ» | 2 на задание (в заданиях с выбором 1) |
| Сохранение | нет | ответы сохраняются, перезагрузка страницы не сбрасывает работу |
| Отправка | кнопкой | **автоматически** после последнего задания + кнопкой |

«Начать заново» в ДЗ выдаёт новый вариант, и учитель видит номер попытки.
Отметка ставится по шкале из `config.js` (`GRADE_SCALE`: «5» от 90 %, «4» от 70 %, «3» от 50 %), её можно изменить под положение школы.

## 🚀 Пошаговая настройка

### Шаг 1. Telegram-бот
1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя и username → скопируйте **токен** вида `1234567890:AA...`.
2. Узнайте свой **chat_id**: напишите [@userinfobot](https://t.me/userinfobot), он ответит числом `Id: 123456789`.
   Для группы: добавьте бота в группу и узнайте id группы через [@myidbot](https://t.me/myidbot) (`/getgroupid`); id группы начинается с `-100…`.
3. **Важно:** откройте своего бота и нажмите **`/start`**. Пока вы этого не сделали, бот не может вам писать (ошибка `chat not found`).

### Шаг 2. Секреты GitHub
`Settings → Secrets and variables → Actions → New repository secret`:

| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | ваш chat_id (или id группы) |

В репозитории токена **нет**: `js/config.js` содержит только плейсхолдеры, а реальные значения подставляются при сборке.

### Шаг 3. GitHub Pages
`Settings → Pages → Build and deployment → Source: **GitHub Actions**`.

### Шаг 4. Публикация
Сделайте пуш в `main` (или `Actions → Deploy to GitHub Pages → Run workflow`). Workflow:
1. запускает тесты `node tests/run-tests.js`;
2. копирует сайт в `_site/` и через `sed` заменяет `__TELEGRAM_BOT_TOKEN__` и `__TELEGRAM_CHAT_ID__` значениями секретов;
3. проставляет `?v=<sha>` для сброса кэша и публикует сайт на Pages.

Сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

### Шаг 5. Проверка связи
* На сайте внизу главной страницы нажмите **«🔔 Проверить связь с Telegram»**: придёт тестовое сообщение.
* Вручную (подставьте свои значения):
  ```bash
  curl -s "https://api.telegram.org/bot<ТОКЕН>/sendMessage" -d chat_id=<CHAT_ID> -d text="Проверка"
  ```
  Ответ `{"ok":true,...}` означает, что всё работает.

| Ошибка | Причина и решение |
|---|---|
| `Неверный токен` (401) | токен скопирован не полностью → обновите секрет и перезапустите workflow |
| `Чат не найден` (400) | не нажали `/start` у бота или ошибка в chat_id |
| `Бот заблокирован` (403) | разблокируйте бота или добавьте его в группу |
| `Отправка не настроена` | секреты не заданы или сайт открыт не с GitHub Pages (локально) |
| `Нет связи с Telegram` | нет интернета или Telegram недоступен в сети школы; результат сохранится и отправится при следующем открытии сайта; есть кнопка «Скопировать результат» |

## 🔐 О безопасности (важно)
* Токен **не хранится в репозитории**, он лежит в GitHub Secrets.
* Но в **опубликованном** сайте токен **виден** в `js/config.js`: браузер должен знать его, чтобы вызвать Bot API. Это осознанный компромисс бесплатного решения без сервера. Что делать:
  * заведите для тренажёра **отдельного бота** и не используйте его ни для чего другого;
  * не давайте боту прав администратора в группах, отключите `Allow Groups` в BotFather, если отправляете в личный чат;
  * при злоупотреблениях: `@BotFather → /revoke` → новый токен → обновите секрет → перезапустите workflow;
  * для полного сокрытия токена используйте прокси на **Cloudflare Workers** (бесплатно): воркер хранит токен в своих секретах и принимает от сайта только текст результата. В `telegram.js` достаточно заменить URL в `rawSend` на адрес воркера.

## 🧪 Разработка
```bash
python3 -m http.server 8080      # открыть http://localhost:8080
node tests/run-tests.js          # проверить все генераторы и проверку ответов
```
**Добавить задание:** в `js/data/algebra.js` или `geometry.js` в массив `gens` нужного урока добавьте функцию `(R) => N('Условие', ответ)`.
Конструкторы: `N` число, `E` выражение (`form: 'expanded' | 'factored' | 'mono' | 'nofrac'`), `P` пара, `L` список, `C` выбор, `M` множественный выбор, `O` порядок шагов, `X` текст, `YN` да/нет. `R.int(a,b)`, `R.nz(a,b)`, `R.pick([...])` — случайные значения из ГСЧ с зерном.
