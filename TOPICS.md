# Перечень тем · Математика 7 класс (алгебра + геометрия)

Перечень составлен по ФГОС ООО (приказ Минпросвещения № 287 от 31.05.2021) и ФОП ООО (приказ № 370 от 18.05.2023,
учебные курсы «Алгебра» и «Геометрия» для 7 класса) с опорой на УМК базового и углублённого уровней.
В тренажёре **64 урока** (алгебра 40, геометрия 24) и **445 генераторов** заданий: каждый генератор выдаёт неограниченное число вариантов.

## 1. Анализ программ по УМК

### Темы только углублённого уровня
* **Алгебра:** математический язык и модель; уравнения с модулем и параметром; элементы комбинаторики; взаимное расположение графиков, y = |x|, кусочные функции; олимпиадные приёмы со степенями; деление многочлена на одночлен, делимость; выделение полного квадрата, наибольшие и наименьшие значения; сокращение алгебраических дробей; системы с параметром; олимпиадный блок.
* **Геометрия:** доказательства с дополнительными построениями; задачи повышенной сложности на параллельность; треугольники (внешние углы, свойства угла 30°, медиана к гипотенузе); геометрическое место точек.

## 3. Типы заданий
| Тип | Как вводится | Как проверяется |
|---|---|---|
| `num` число / дробь | `12`, `−3,5`, `7/2`, `3 1/2`, `40°`, `12 см` | числовое сравнение; запятая или точка, единицы измерения отбрасываются |
| `expr` выражение | `x^2+2x+1`, `x²+2х+1`, `y = 3x − 5` | подстановка 7 наборов случайных значений + проверка формы записи (раскрыты скобки / разложено на множители / стандартный вид одночлена / дробь сокращена); кириллические «х», «у», «а» распознаются |
| `coord` координаты | `(2; −3)`, `2, −3`, `x=2, y=−3` | покомпонентное сравнение |
| `list` список | `−2; 3` | сравнение без учёта порядка (или с учётом, если `ordered`) |
| `choice` / `multi` | кнопки | индекс(ы) верных вариантов |
| `order` | шаги нажимают по порядку | доказательства и алгоритмы построения |
| `text` | словами | ключевые слова (`серединн` + `перпендикуляр`), регистр и ё/е не важны |
